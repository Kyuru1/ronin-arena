COMO ENVIAR O JOGO PARA O GITHUB

Repositorio: Kyuru1/ronin-arena
Endereco do jogo: https://Kyuru1.github.io/ronin-arena/

1. Abra o GitHub Desktop.

2. Selecione o repositorio local "ronin-arena".
   Se ele nao aparecer na lista, use File > Add local repository e selecione
   a pasta deste projeto.

3. Confira os arquivos alterados na aba Changes.

4. No campo Summary, escreva uma mensagem de commit.
   Exemplo:

   Configura deploy automatico no GitHub Pages

5. Clique em "Commit to main".

6. Se for a primeira vez que este repositorio sera enviado ao GitHub, clique
   em "Publish repository" ou "Publish".

7. Nas proximas vezes, clique em "Push origin" para enviar as alteracoes.

8. Depois do push, o GitHub Actions fara o build e o deploy automaticamente.
   Aguarde alguns minutos e abra:

   https://Kyuru1.github.io/ronin-arena/

CONFIGURACAO NECESSARIA NO GITHUB

No repositorio do GitHub, abra:

Settings > Pages

Em "Build and deployment", deixe "Source" selecionado como:

GitHub Actions

Isso precisa ser configurado uma vez para o deploy automatico funcionar.

RANKING ONLINE

Quando a API PostgreSQL estiver hospedada em um endereco HTTPS publico, crie no
GitHub o secret VITE_RANKING_API_URL com o endereco terminado em /api:

Settings > Secrets and variables > Actions > New repository secret

Exemplo: https://api.seudominio.com/api

Sem esse secret, o jogo publicado continua funcionando, mas usa o ranking salvo
no navegador de cada jogador quando a API local nao estiver acessivel.
